Auto search @if (status()?.autoSearch?.running) { Running }

Each run picks the least-recently-searched monitored volumes that still have missing Standard issues, searches Prowlarr for them and sends the best torrents to qBittorrent — only results scoring at or above the minimum score are considered, highest first. A SINGLE torrent is grabbed for the issue it targets; a PACK is added paused, its files are matched by issue number, and it is removed again if it contains none of the missing issues. Usenet results are ignored. Only Standard issues are fetched — specials and omnibus are never acquired automatically.

Least-recently-searched first.
